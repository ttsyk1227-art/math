解き方の4ステップ

グラフを利用する方法
  1. 判別式 D = b² − 4ac の符号を調べ、実数解の個数を確認する。
  2. 方程式 ax² + bx + c = 0 を因数分解または解の公式で解き、解を求める（D < 0 なら実数解なし）。
  3. グラフの概形を描く。a > 0 なら下に凸、a < 0 なら上に凸。
  4. グラフがx軸より上・下どちらにあるかを、与えられた不等号の向きと照らし合わせて解を読み取る。
