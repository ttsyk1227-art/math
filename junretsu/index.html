単元 1

和の法則・積の法則

和の法則：AとBが同時には起こらないとき、「AまたはB」の起こり方は a + b 通り。

積の法則：Aの起こり方が a 通りで、そのそれぞれに対してBが b 通りあるとき、「AとB」の起こり方は a × b 通り。

例 大小2個のサイコロで、目の和が5の倍数になる（和が5か10）。 和が5：(1,4)(2,3)(3,2)(4,1) の4通り、和が10：(4,6)(5,5)(6,4) の3通り → 4 + 3 = 7通り
例 シャツ3枚、ズボン4本の組み合わせ方 → 3 × 4 = 12通り

すべての場合の数は、この2つの法則の組み合わせでできています。迷ったら樹形図をかいて確かめましょう。

単元 2

順列 nPr と階乗 n!

nPr = n(n−1)(n−2)…(n−r+1)　← nから始めて r 個かける
n! = n(n−1)…2・1 = nPn　　0! = 1

異なる n 個から r 個を取り出して一列に並べる並べ方です。1番目は n 通り、2番目は残りの (n−1) 通り…と積の法則で考えます。

例 1〜6の数字から異なる3個で3桁の整数 → 6P3 = 6×5×4 = 120個
よく出る型 ・隣り合う：隣り合うものをまとめて1つと考え、あとで中の並び方をかける。 ・隣り合わない：先に他のものを並べ、その間と両端に入れる。 ・0を含む整数：最高位に0は置けない。最高位から決める。
単元 3

円順列・じゅず順列

円順列 = (n−1)!　　じゅず順列 = (n−1)!2

円形に並べると、回転して重なるものは同じ並び方です。1人を固定して残りの (n−1) 人を並べると考えます。じゅず（首飾り）は裏返しても同じなので、さらに2で割ります。

例 5人が円卓に座る → (5−1)! = 4! = 24通り 例 異なる5個の玉で首飾り → 4! ÷ 2 = 12通り
単元 4

重複順列 nr

異なる n 種類から、重複を許して r 個並べる → nr 通り

毎回 n 通りの選び方があるので、n を r 回かけます。「人をどの部屋に入れるか」のように、1人ずつ行き先を選ぶ問題もこの形です。

例 5人をA, Bの2部屋に入れる（空き部屋があってもよい） → 25 = 32通り どちらの部屋にも1人以上 → 全員Aと全員Bの2通りを引いて 32 − 2 = 30通り
単元 5

組合せ nCr

nCr = nPrr! = n(n−1)…(n−r+1)r(r−1)…1　　nCr = nCn−r

異なる n 個から r 個を選ぶだけ（順番を区別しない）の数です。順列 nPr では、同じ r 個の組が r! 回ずつ数えられているので r! で割ります。下の「書き出しラボ」で確かめられます。

例 10人から8人を選ぶ → 10C8 = 10C2 = 10×9÷2 = 45通り 例 「少なくとも1人」→ 全体から「1人もいない」を引く（余事象）。 例 正六角形の対角線 → 2頂点の選び方 6C2 = 15 から辺の6本を引いて 9本
単元 6

同じものを含む順列・最短経路

a が p 個、b が q 個、c が r 個 → (p+q+r)!p! q! r! 通り

同じもの同士を入れかえても並びは変わらないので、その入れかえの数で割ります。2種類なら、「どの場所に a を置くか」を選ぶと考えて p+qCp でも求められます。

最短経路：右に a 回、上に b 回進む道順は、「→ a 個と ↑ b 個の並べ方」なので a+bCa 通り。点Pを通る道は「A→P の道順 × P→B の道順」。

例 上の図で A から B への最短経路 → →4個、↑3個の並べ方 7C3 = 35通り P を通るもの → A→P は 3C1 = 3、P→B は 4C2 = 6 なので 3 × 6 = 18通り
単元 7

組分け

人を組に分けるときは、組に名前（A組、B組など）があるかどうかが分かれ目です。

例 6人を2人ずつ A, B, C の3部屋に分ける → 6C2 × 4C2 × 2C2 = 15 × 6 × 1 = 90通り 部屋の区別がない3組に分ける → 同じ人数の組の入れかえ 3! 通りが同じになるので 90 ÷ 3! = 15通り 6人を1人・2人・3人の3組に分ける → 人数が違うので組を区別できる。6C1 × 5C2 = 60通り（割らない）
単元 8　発展

重複組合せ（○と｜の並べ方）

「同じりんご 5 個を A, B, C の 3 人に分ける（0 個の人がいてもよい）」は、○ 5 個としきり ｜ 2 本の並べ方と同じです。

○○｜○｜○○　→　A 2 個、B 1 個、C 2 個
7C2 = 21 通り

x + y + z = n（0以上の整数）の解の個数も同じで n+2C2。1以上の整数にしたいときは、先に1個ずつ配ってから考えます。

さわって確かめる

書き出しラボ

A, B, C, … から r 個を取り出す並べ方をすべて書き出します。同じ組（左の青字）ごとに r! 個ずつ並びがあるので、nPr = nCr × r! になることを確かめましょう。
