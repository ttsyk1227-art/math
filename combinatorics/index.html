公式まとめ

問題を解く前に、まず「どの公式を使うか」を決めよう。

どの公式を使う？ 見分け方

  1. 同じものを何回も選べる（くり返しOK）？
    → 並べるなら 重複順列 nr、選ぶだけなら 重複組合せ nHr
  2. 並べるものの中に、同じものが含まれている？
    → 同じものを含む順列
  3. 円形に並べる？
    → 円順列 (n−1)!（裏返せる首飾りなどは さらに ÷2）
  4. 順番や役割の区別がある？
    → ある：順列 nPr　ない（選ぶだけ）：組合せ nCr

階乗

n! = n × (n−1) × … × 2 × 1

1 から n までの積。0! = 1 と約束する。

例：4! = 4 × 3 × 2 × 1 = 24

順列

nPr = n(n−1)(n−2)…(n−r+1)

異なる n 個から r 個を取り出して並べる。n から1ずつ減らして r 個かける。

キーワード：並べる・1列・役職（委員長と副委員長）・けたの整数

例：5人から3人選んで1列に並べる　5P3 = 5 × 4 × 3 = 60通り

組合せ

nCr = nPrr!

異なる n 個から r 個を選ぶだけ（順番は関係ない）。並べた後で、r! 通りの並べかえの分だけ割る。

キーワード：選ぶ・組・委員（役職なし）・三角形・試合数

例：5人から3人の委員を選ぶ　5C3 = 5 × 4 × 33 × 2 × 1 = 10通り

便利な性質：nCr = nCn−r　（10C8 = 10C2 = 45）

円順列

(n − 1)!

異なる n 個を円形に並べる。回転して重なるものは同じなので、1つを固定して残りを並べる。

キーワード：円形のテーブル・輪になる

例：5人が円形に座る　(5−1)! = 4! = 24通り

じゅず順列（首飾り・腕輪）：(n − 1)!2　裏返して同じものも1通り

重複順列

nr

n 種類から同じものを何回使ってもよいとして r 個並べる。1つずつ n 通りずつ選べる。

キーワード：何回使ってもよい・じゃんけん・部屋に分ける・○×

例：3人がじゃんけん　33 = 27通り

同じものを含む順列

n!p! q! r! …

n 個の中に、同じものが p 個、q 個、r 個…あるときの並べ方。同じものどうしの入れかえ分を割る。

キーワード：文字の並べかえ・最短経路

例：a, a, b, b, b を並べる　5!2! × 3! = 10通り

重複組合せ 発展

nHr = n+r−1Cr

n 種類から同じものを何個選んでもよいとして r 個選ぶ。「○ r 個と仕切り｜(n−1) 本の並べ方」と考える。

キーワード：〜種類から〜個買う・x+y+z=n の整数解

例：3種類の果物から5個買う　7C2 = 21通り
