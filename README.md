# math
数学学習のための学習アプリ

## 計算ドリル

`index.html` をブラウザで開くだけで使えます（ビルド不要）。

- たし算・ひき算・かけ算・わり算から出題する種類をえらべます（複数可）
- むずかしさ（1〜3けた）と問題数（10 / 20 / 50問）をえらべます
- タイマー、正解数、まちがえた問題の見直しを表示します
- 設定ごとのベスト記録をブラウザに保存します
- スマホでは画面上のテンキーで入力できます

## 順列と組合せ道場

高校数学A「場合の数」の練習用ページです。`junretsu/index.html` をブラウザで開くだけで使えます（計算ドリルの画面下のリンクからも開けます）。

- **学ぶ**：和・積の法則、順列、円順列、重複順列、組合せ、同じものを含む順列・最短経路、組分け、重複組合せ（発展）の解説と、すべての並べ方を書き出す「書き出しラボ」
- **トレーニング**：単元ごとに数字を変えた問題が毎回作られます。ヒント・解説つき
- **演習問題**：基本演習10問・応用演習10問。採点して解説を確認できます
