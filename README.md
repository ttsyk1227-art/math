# math
数学学習のための学習アプリ

## 計算ドリル

`index.html` をブラウザで開くだけで使えます（ビルド不要）。

- たし算・ひき算・かけ算・わり算から出題する種類をえらべます（複数可）
- むずかしさ（1〜3けた）と問題数（10 / 20 / 50問）をえらべます
- タイマー、正解数、まちがえた問題の見直しを表示します
- 設定ごとのベスト記録をブラウザに保存します
- スマホでは画面上のテンキーで入力できます

## 順列・組合せトレーナー（高校数学A）

`combinatorics/index.html` を開くと使えます。計算ドリルの画面下のリンクからも移動できます。

- **公式まとめ**：階乗・順列・組合せ・円順列・重複順列・同じものを含む順列・重複組合せ（発展）と、どの公式を使うかの見分け方
- **計算トレーニング**：n!・nPr・nCr の計算
- **文章題トレーニング**：分野とレベル（基本・標準）を選ぶと、毎回ランダムに問題が出ます。ヒントと解説つき
- **見分けクイズ**：問題文を読んで、使う公式を選びます
- **演習問題**：テスト形式の全10問・30小問。大問ごとに採点と解説を表示します

## 確率の解き方ナビ（高校数学A）

`probability/index.html` を開くと使えます。問題文の「ことば」から、どの解き方を使うかを判断できるようにするアプリです。

- **解き方ガイド**：基本・余事象・和事象・独立な試行・反復試行・条件付き確率（乗法定理）・最大値と最小値・期待値の8つについて、見分ける順番、キーワード、公式、手順、例題をまとめています
- **問題チェック**：問題文を入力すると、手がかりになることばに色をつけて、使う解き方と手順を表示します
- **見分けクイズ**：問題文を読んで、使う解き方を選びます
- **ドリル**：解き方とレベルを選ぶと、毎回ランダムに問題が出ます。分数で答え、解説で確認できます

## 場合の数 パターン練習（高校数学A）

`patterns/index.html` を開くと使えます。場合の数の問題を「並べる・選ぶ・分ける」に分け、条件ごとに28のパターンに整理しています。

- **早見表**：条件 → 考え方 → 式 → 例。見分ける4ステップ、いつでも使える8つの考え方、まちがえやすいポイントつき
- **パターン当て**：問題文を読んで、使う考え方を4つから選びます
- **ドリル**：グループやパターンを選んで練習します。まちがえたパターンを多めに出すこともできます
- **プリント**：`patterns/print.html` を開いて「印刷する」を押すと、A4のプリント（まとめ2ページ、確認テスト28問、解答）を印刷できます。同じ内容のPDFが `patterns/print.pdf` にあります

問題と解説のデータは `patterns/data.js` にまとめてあり、アプリとプリントの両方で使っています。

### 確率のプリント

`probability/print.html` を開いて「印刷する」を押すと、A4のプリントを印刷できます。内容は、確率の基本・見分ける順番・まちがえやすいポイント・8つの解き方のまとめが2ページ、確認テスト全31問、解答です。同じ内容のPDFが `probability/print.pdf` にあります。問題と解説のデータは `probability/data.js` にまとめてあり、アプリとプリントの両方で使っています。
